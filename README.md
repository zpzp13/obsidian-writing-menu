# Writing Menu

Obsidian을 위한 글쓰기 환경 커스터마이징 플러그인입니다.

![Obsidian](https://img.shields.io/badge/Obsidian-v1.0.0+-purple)
![License](https://img.shields.io/badge/license-MIT-blue)

## 기능

### 타이포그래피

- **글꼴**: 커스텀 글꼴 설정
- **글자 크기**: 픽셀 단위 조절
- **줄간격**: 줄 사이 간격 조절
- **문단간격**: 문단 사이 간격 조절
- **너비**: 편집 영역 너비 조절
- **들여쓰기**: 첫 줄 들여쓰기
- **글자색**: 라이트/다크 테마별 개별 설정
- **배경색**: 라이트/다크 테마별 개별 설정
- **링크 색상**: 링크 색상 비활성화 옵션

### 글쓰기 보조

- **타자기 스크롤**: 커서가 항상 화면 중앙에 위치
- **포커스 모드**: 현재 줄 외의 텍스트를 흐리게 표시 (투명도 조절 가능)

### 스마트 입력

- **스마트 따옴표**: 곧은 따옴표(`"`, `'`)를 둥근 따옴표(`""`, `''`)로 자동 변환
- **스마트 엔터**: 괄호 안에서 엔터 입력 시 닫는 괄호 아래로 커서 이동
- **자동완성**: 트리거 키 입력 시 기호 쌍 팝업 표시, 선택한 기호 쌍 자동 입력
- **텍스트 치환**: 특정 텍스트를 다른 문자로 자동 변환 (예: `-->` → `→`)

### 기타

- **글자 수 카운터**: 탭 헤더에 실시간 글자 수 표시, 선택 영역 글자 수 지원
- **폴더별 적용**: 특정 폴더에만 스타일 적용 가능

## 설치

### 수동 설치

1. [Releases](https://github.com/YOUR_USERNAME/writing-menu/releases) 페이지에서 최신 버전 다운로드
2. `main.js`, `manifest.json`, `styles.css` 파일을 Obsidian vault의 `.obsidian/plugins/writing-menu/` 폴더에 복사
3. Obsidian 설정 → 커뮤니티 플러그인에서 "Writing Menu" 활성화

## 사용법

### 탭 헤더 메뉴

각 마크다운 탭의 헤더에 있는 설정 아이콘을 클릭하면 빠른 설정 메뉴가 열립니다.

### 플러그인 설정

Obsidian 설정 → 커뮤니티 플러그인 → Writing Menu에서 상세 설정을 변경할 수 있습니다.

- **자동완성**: 트리거 키와 기호 쌍을 추가/수정/삭제
- **텍스트 치환**: 변환 규칙 추가/수정/삭제

## 기본 텍스트 치환 규칙

| 입력 | 변환 |
|------|------|
| `-->` | → |
| `<--` | ← |
| `<->` | ↔ |
| `=>` | ⇒ |
| `...` | … |
| `1/2` | ½ |
| `1/4` | ¼ |
| `3/4` | ¾ |
| `!=` | ≠ |
| `<=` | ≤ |
| `>=` | ≥ |
